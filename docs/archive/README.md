# Archive

Build-time artifacts kept for provenance, **not current truth**. Nothing here is
maintained against the code, and no current document links into it — when it
disagrees with [`docs/design.md`](../design.md), the design wins.

- `specs/` — the dated design specs (`YYYY-MM-DD-*-design.md`) written while a
  feature was being built. Each is a snapshot of intent at its date, often in the
  vocabulary of the day (`carve`, `queue`); the ADR it cites and the current design
  section carry the decision now.

To find the current rule, read `docs/design.md` (implementation truth) and the
ADRs under `docs/adr/` (why a decision was taken).
