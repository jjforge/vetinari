section: Bug fixes
- [ops] Host-side git no longer prompts for credentials on a terminal: vetinari sets `GIT_TERMINAL_PROMPT=0` on its own process when the config loads, so a pre-worktree fetch with no usable credential fails fast instead of blocking until `Worktree creation timed out after 30000ms` stops the campaign. A project can override it in `hostEnv` (#398).
