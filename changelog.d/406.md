section: New features
- [ops] Vetinari now ships its operator skills in `skills/` — `/fileset` (fill in file-set markers before a campaign), `/triage-placement` (place issues under epics and wire native `blocked_by` edges) and `/verify-pending` (check `pending-verify` issues on the base and close the resolved ones) — and `scripts/install-skills.sh` links them into `~/.claude/skills`, so every project on the machine uses one copy that tracks the checkout instead of a per-repo copy that drifts. `/fileset` no longer hard-codes this repo and now warns against citing the changelog fragment (#406).
