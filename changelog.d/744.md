section: Improvements
- [ops] On macOS, `vetinari gateway install` now writes a launchd LaunchAgent (`~/Library/LaunchAgents/vetinari-gateway.plist`) that starts the gateway at login and keeps it running, carrying the installing shell's PATH and gateway settings. `gateway status|start|stop|restart` drive it through `launchctl`, and it logs to `~/Library/Logs/vetinari-gateway.log`. These commands used to refuse on macOS (#744).
