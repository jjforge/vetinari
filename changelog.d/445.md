section: New features
- [user] Slow gates are flagged: at every wave settle (after the wave-done line, or beside the stop line when a wave parks or fails) the terminal names a gate whose campaign median green run is ≥ 1.5× and ≥ 30s over the median of all its earlier green runs (once per campaign, even across a redrive), and the dashboard project page shows a "Slow gates" section while the latest campaign has one. Information only — no verdict, park or exit code depends on it (#445).
- [ops] A gate can set `budgetSeconds`; any run over it — green or red — is flagged as a slow gate at each settle whose wave had one. The budget is logged on each `gate-result`, so the dashboard reads it without the project config (#445).
