section: Bug fixes
- [user] A cite that starts with `./` is now a rooted cite: it names one path from the repository root and matches only that exact path, so `Touches: ./README.md` pins the root `README.md` even when `docs/README.md` exists, and `Creates: ./a/new.ts` keys to `a/new.ts` with no directory suffix matching. A bare `README.md` still means any `README.md`. The `/fileset` skill now writes root files as `./<name>` (#627).
- [ops] `loadConfig` refuses a `waivedFiles` entry starting with `./`, naming it and the file key to write instead, rather than silently waiving nothing (#627).
