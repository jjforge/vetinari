section: New features
- [user] `vetinari init` now checks for the GitHub labels the `githubTracker()` config relies on (`ready-for-agent`, `pending-verify`, `needs-triage`) when it writes that config. On a terminal it reads the repo's labels with `gh` and offers to create any that are missing; if you decline, or `gh` can't read the labels, it prints the `gh label create` commands instead. Off a terminal, or with `--dry-run`, it makes no `gh` call and prints the commands for all three (#482).
