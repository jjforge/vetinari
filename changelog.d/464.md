section: Bug fixes
- [user] A `--now` stop (`vetinari stop --now`, a second Ctrl-C, or closing the terminal) now pauses the campaign instead of failing it when the signal kills a run before it can park itself — while it is still starting, or as it exits after its verdict. The campaign parks that run `stopped` itself (or, if it still holds a parked record, keeps that record as it is), a run that already reached a verdict keeps it, and `vetinari redrive` picks the campaign up without `--override` or a prune. A run killed by a signal with no stop requested is still a failure, now named by the signal (`error(SIGKILL)`, not `error(null)`) (#464).
