section: New features
- [user] A new optional config field `waivedFiles` names files co-wave tickets may both edit — a large, sectioned doc most tickets update. The planner, the `campaign --dry-run` file-set listing and `graft` leave a fileKey exactly equal to an entry out of collision checks, so tickets that share only a waived file can share a wave; the plan prints `` `<path>` waived for N tickets ``. Tickets still cite the file on `Touches:`. An entry that is a directory refuses `campaign`, `campaign --dry-run` and `graft`; under `packageScopedFileSet` a single `.go` file cannot be waived (#621).
- [api] `campaign-start` carries an optional `waived` field (waived file → how many scheduled tickets cited it), absent when nothing was waived (#621).
