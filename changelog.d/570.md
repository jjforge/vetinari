section: Bug fixes
- [ops] Every parked-record write now goes through one lock per parked directory (`parked/.lock`), so an answer can no longer be lost to a concurrent announce, and an answered parked record that was already consumed can no longer be written back and re-run. An answer whose record is cleared just before delivery now reports `<id> is not parked — nothing to answer.` and logs no `answered` (#570).
