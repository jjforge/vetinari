section: Bug fixes
- [user] `campaign` and `redrive` now exit with the campaign's verdict — 0 only after `campaign-done`, 2 after a `campaign-parked`, 1 after a `campaign-failed` — instead of exiting 0 whatever happened; the same codes reach you through `answer`'s implicit redrive (#313).
- [user] `run` now distinguishes a failed turn (exit 1) from a park (exit 2), matching the terminal's "green, parked, or failed"; a standalone run that throws now leaves a `failed` verdict on the event log instead of dying silently (#313).
- [ops] `prune --dry-run` / `graft --dry-run` no longer print their machine-readable closure JSON to stdout unless `--json` is passed, so a bare dry-run leaves clean prose output (#313).
